## Сохранение

- Результат сохраняется в отдельный файл. Перезапись открытого исходника запрещена, включая альтернативное написание пути и жёсткие ссылки.
- Данные записываются во временный файл рядом с целевым, затем выполняется атомарная замена. Перед заменой существующего результата создаётся `.bak.<дата>.<идентификаторы>`. Ошибка резервного копирования прерывает сохранение.
- Нетронутые блоки проверяются на побайтовое совпадение. Отчёт `.report.json` содержит сведения о перепаковке и затронутых смещениях.
- Ошибка записи отчёта сообщается отдельно: сохранённая прошивка остаётся на диске, но отчёт не считается обновлённым.
- Бюджет Undo/Redo — 16 МиБ. Старые записи удаляются; действие, превышающее бюджет, применяется без возможности отмены.

Проверки перепаковки не заменяют проверку работы прошивки на устройстве. Сохраняйте исходный образ.
