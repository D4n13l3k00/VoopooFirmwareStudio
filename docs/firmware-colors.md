# Цвета предпросмотра VOOPOO DRAG

Предпросмотр использует значения RGB565, которые получает отрисовка прошивки.
Цвета масок задаёт вызывающий код; изменение битмапа не меняет его цвет.
Для ресурса, который зависит от режима или ранга, доступны соответствующие
параметры предпросмотра. Одна маска может выглядеть по-разному в разных режимах.

DRAG, DRAG 2 и mini используют монохромные маски без RGB565-палитры и цветовых тем. Таблицы ниже описывают S/X.

## Score A050 / E050

| Ресурсы | Цвет рисунка | Фон | Изменяется темой |
|---|---|---|---|
| SMART | `accent_red` | Чёрный | Да |
| RBA | `accent_cyan` | Чёрный | Да |
| Mode P/A (только DRAG S), Puff, Time, Ohm, V | Акцент выбранного режима | Чёрный | Да |
| Toggle off | `accent_red` | Чёрный | Да |
| Toggle on | Фиксированный зелёный | Чёрный | Нет |
| Цифры 19×40 | `digits_wattage` | Чёрный | Да |
| Цифры 11×20 | `digits_stats` | Акцент выбранного режима | Да, рисунок и фон |
| Цифры 6×10 и 7×13, W, S, десятичная точка | Белый | Чёрный | Нет |
| Rank icon 0/2 | Цвет из таблицы рангов, штатно белый | Чёрный | Нет |
| Rank icon 1/3/4/5/6/7 | Соответствующий цвет ранга | Чёрный | Да |
| Rank label | Белый | Чёрный | Нет |
| Meter frame 0–7 | Цвет выбранного ранга | Чёрный | Для цветных рангов |
| State frame 0–5 | `highlight_yellow` | Чёрный | Да |
| VOOPOO header, CHIP ID, LEVEL CODE | `highlight_yellow` | Чёрный | Да |
| Battery frame и символ после процента заряда | Белый | Чёрный | Нет |
| Dialog/alert: рамки и текст | Белый | Чёрный | Нет |
| Логотип DRAG S / DRAG X, ACTIVATED и цветные значки предупреждений | Фиксированные цвета соответствующих вызовов | Чёрный | Нет |
| Animated boot и OFF (RGB565) | Цвет каждого пикселя из битмапа | Из битмапа | Нет |

Фиксированные цвета логотипа, ACTIVATED, предупреждений и включённого
переключателя считываются из канонической секции модели: `3103` для DRAG S,
`3106` для DRAG X. Адреса инструкций и таблицы рангов у моделей различаются.
У DRAG S таблица рангов находится по адресу `0x08010604`.

Места отрисовки `3103`: статус `0x08007E94`; загрузка `0x08008024`;
зарядка `0x080085D4`; предупреждения `0x08008564` и `0x080088D8–0x08008CB8`;
режим/переключатель `0x0800AD58`; мощность `0x0800AE78`;
Puff/Time `0x0800AEF8`; сопротивление `0x0800B2F4`;
счётчик `0x0800B42C`; ранги `0x0800B5CC`; длительность `0x0800BA80`;
сервисные панели `0x0800DF88`.

## Factory

- `accent_red` и `accent_cyan` — основные режимы и двухцветная таблица интерфейса.
- `digits_wattage` и `digits_stats` — крупные и малые числовые показания.
- `highlight_yellow` — сервисные панели; `service_green` — отдельные зелёные элементы старых ревизий.
- Роли рангов Score в Factory отсутствуют.

Factory смешивает RGB565, RGB888 и разные исходные цвета аппаратных ревизий. Без правок байты каждой ревизии сохраняются; «Заводская по умолчанию» восстанавливает палитру соответствующей редакции, а не Score.

## PRO, PLUS, DRAG 3 и MAX

Палитра определяется нативными вызовами отрисовки конкретного образа. Цвета режимов, цифр и предупреждений редактируются отдельно; у PRO светлые и тёмные варианты режимов — независимые ячейки таблицы. Повёрнутые маски используют цвета тех же нативных вызовов.

Темы сопоставляются с доступными ролями устройства. Заводская тема восстанавливает исходные значения каждой аппаратной ревизии, включая различия внутри одного пакета. Произвольная перекраска чёрного фона не поддерживается.

## Проверка

`--smoke-test` перепаковывает темы и дополнительную палитру с небелыми
цифрами для Score и Factory обеих моделей, повторно открывает контейнер
и сравнивает цвета с предпросмотром. Проверки редактора читают текстуры с GPU.

Независимый ARM-аудит ниже относится только к DRAG S **Score A050** / `3103`; Factory и DRAG X им не проверяются.
Установите Python-пакеты `unicorn` и `capstone`, затем выполните из корня репозитория:

```powershell
$env:VOOPOO_COLOR_AUDIT_DIR = Join-Path $env:TEMP 'voopoo-color-audit'
$p = Start-Process '.\build\Release\VoopooFirmwareStudio.exe' -ArgumentList '--smoke-test' -PassThru
$p.WaitForExit()
if ($p.ExitCode -ne 0) { throw 'Smoke test failed' }
py tests/audit_firmware_colors.py $env:VOOPOO_COLOR_AUDIT_DIR
Remove-Item Env:VOOPOO_COLOR_AUDIT_DIR
```

Скрипт исполняет инструкции вызывающих функций `3103` и настоящий конвертер
RGB888→RGB565. Он сравнивает переданные цвета и размеры с предпросмотром,
включая два режима и восемь рангов. Работа с дисплеем, периферией, задержками
и выделением памяти заменена тестовыми обработчиками. Устройство не нужно.

Проверка относится к значениям пикселей RGB565 и поддерживаемой компоновке
A050. Яркость, гамма и цветопередача физического экрана могут отличаться от
монитора ПК.
